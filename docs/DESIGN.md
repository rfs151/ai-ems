# 储能 EMS 边缘网关演示项目 · 详细设计

> 状态：v0.3（2026-11-04），第 1~3 阶段的主要业务功能已实现；演示范围只做主要业务功能
> 访问地址（规划）：https://ems.edgebot.vip

## 1. 目标与定位

面向招聘 **储能 EMS / 边缘网关 / 嵌入式 C** 方向的面试官，让对方在浏览器里**操作并看到控制效果**，而不是只看文字。

每个演示点对应简历中的一条经历：

| 简历经历 | 演示中怎么体现 |
|---|---|
| 多厂商设备接入（Modbus 点表适配） | 3 种不同点表格式的模拟设备，"设备与点表"页展示同一个统一模型如何映射到不同厂商寄存器 |
| mFRR 四阶段轨迹、计划/直接激活、同向叠加 | 控制台下发 mFRR 指令，曲线上实时看到爬坡/保持/降坡，以及第二条同向指令的平滑交接 |
| LFSM-O 过频下垂、FCR 协同 | 拖动"电网频率"，看到 FCR 与 LFSM-O 分量叠加到总功率 |
| TinyExpr 规则引擎（排序 + 二分查找） | 在页面上增删规则，触发后告警和 DO 联动实时出现 |
| 上云进程拆分、MQTT TLS、批量上报 | 页面显示云边链路状态、上报批次、指令往返时延；可模拟断网，看离线缓存和补传 |
| SQLite WAL、锁竞争优化 | "技术要点"页给出压测对比数据 |
| 固件 RSA+SHA256 签名校验 | 上传固件包，网关校验签名并显示结果（篡改包被拒绝） |
| 104 / 61850 | EMS 作为 104 子站，接入现有 ai-scada 主站，在 SCADA 里出现一个"储能站" |

**原则**：代码全部重新编写，不使用任何公司代码、文档或真实厂商协议细节。厂商用虚构名称（"厂商 A/B/C"），寄存器布局自行设计。

语言分工：**展示重点 ems-core / ems-sync 用 C99**，和简历技术栈一致；设备仿真和云端只是配角，用 Python 快速实现。

### 2.1 仿真的储能站

| 设备 | 厂商 | 点表特点（用于展示适配能力） |
|---|---|---|
| PCS-1 500kW | 厂商 A | 保持寄存器，int16 + 倍率 0.1，大端字序 |
| PCS-2 500kW | 厂商 B | float32，**低字在前**（CDAB），控制需先写使能字再写设定值 |
| 电池簇-1 1MWh | 厂商 B | 输入寄存器，单体电压用 uint16 数组批量读取 |
| 电池簇-2 1MWh | 厂商 C | uint32 累计电量，状态位按 bit 打包，告警码查表 |
| 关口电表 | 通用 | 并网点有功/无功/频率（频率来自仿真信号源） |
| DI/DO 模块 | 通用 | 急停、消防、门禁（DI），并网开关、风机（DO） |

仿真物理模型：PCS 跟随设定值，带一阶响应延迟和爬坡限制；SOC 按功率积分；电池温度随功率缓慢变化；频率 = 50Hz + 低幅噪声 + 注入扰动。

## 3. ems-core 模块划分

| 模块 | 职责 | 设计要点 |
|---|---|---|
| `config` | 加载站点、设备、点表配置（JSON） | 厂商差异全部写在配置里：数据类型、字序、倍率、偏移、读写功能码；只有特殊控制时序才用少量 C 钩子 |
| `modbus` | libmodbus 封装 | 连续寄存器合并成批量读；超时、断线重连、指数退避 |
| `acq` | 采集调度 | 每台设备一个线程；快组 200ms（功率、频率）、慢组 5s（温度、单体电压）；连续失败 N 次判离线，数据带质量位 |
| `rtdb` | 实时库 | 点位数组 + 读写锁；变化回调通知规则引擎和存储；快照接口供控制循环一次性读取 |
| `control` | 功率控制 | 100ms 控制周期，见第 4 节 |
| `rules` | 规则引擎 | TinyExpr 表达式；规则存 SQLite，加载后按触发点位排序，二分查找命中规则；动作：告警、写 DO、切模式 |
| `alarm` | 告警与事件 | 异步事件队列（环形缓冲 + 条件变量）；告警生命周期：产生 → 确认 → 恢复 |
| `storage` | 本地存储 | SQLite WAL + busy_timeout + (point_id, ts) 复合索引；批量事务写入；按天滚动清理；outbox 表供 ems-sync 读取 |
| `iec104` | 104 子站 | lib60870-C；遥测（功率、SOC）、遥信（运行状态、告警），遥调（有功设定） |
| `ota` | 固件校验 | OpenSSL RSA-2048 + SHA256 验签；构建脚本生成签名包 |
| `util` | 日志、时钟、环形缓冲 | zlog；统一使用单调时钟，不受系统改时影响 |

**ems-sync（独立进程）**：flock 单实例锁；MQTT TLS（libmosquitto）；从 outbox 批量取数据，每 1s 或满 200 条打包上报；断网时数据留在 outbox，恢复后按时间顺序补传；接收下行指令，校验后通过 unix socket 转给 ems-core。

## 4. 功率控制设计

总功率由各项业务分量叠加，再统一限幅：

```
P_cmd = P_base + P_mFRR + P_FCR + P_LFSM-O
P_out = clamp(P_cmd, SOC 允许范围, PCS 可用容量) → 爬坡率限制 → 按可用容量分配到 PCS-1/PCS-2
```

- **FCR**：死区 ±10mHz，±200mHz 满出力，线性下垂。
- **LFSM-O**：开关、启动频率（默认 50.2Hz）、下垂系数（默认 2%）可配置、可远程修改。以叠加后的当前出力为参考功率：ΔP = P × (f − f_start) / 50 / droop，只削减放电，最多削到 0；充电或停机时不调整。
- **mFRR**：
  - 指令字段：方向、功率、激活方式（计划 / 直接）、开始时间、持续时间。
  - 计划激活：校验是否落在允许的时间窗口（可配置，例如 15 分钟边界）；直接激活：立即生效。
  - 轨迹：准备（已激活、功率为 0）→ 爬坡 → 保持 → 降坡 → 结束。实际业务准备 2.5 分钟、爬坡 10 分钟、1 秒一档，演示按 15 分钟 → 60 秒等比缩短为 6s / 24s / 1s。交付结束时刻本身进入降坡（边界用 ≥）。
  - 激活时间校验：计划激活迟到但仍在准备期内照常执行，超过准备期拒绝；直接激活可带开始时间，提前量 0 ~ 60s（实际 15 分钟）。
  - 同向指令叠加：新指令到达时，从当前实际值平滑过渡到新目标，不出现台阶跳变。
  - 反向指令：按配置拒绝，或先降到 0 再反向。
- **SOC 保护**：SOC < 10% 禁止放电，> 95% 禁止充电，边界附近线性降额。
- **下发间隔**：同一台 PCS 两次写设定值至少间隔 300ms（可配置），期间的变化合并；联锁清零不受限。
- **规则闭锁**：规则引擎的 stop 动作按联锁处理，功率降为 0，规则恢复后解除。
- **单元测试**：mFRR 轨迹、叠加交接、FCR/LFSM-O 曲线均用表驱动测试覆盖，CI 中带 ASan/UBSan 运行。

## 5. 通信设计

### MQTT 主题

| 主题 | 方向 | 内容 |
|---|---|---|
| `ems/{site}/telemetry` | 上行 | 批量遥测（压缩 JSON） |
| `ems/{site}/event` | 上行 | 告警、事件 |
| `ems/{site}/status` | 上行 | 在线状态（遗嘱消息 LWT） |
| `ems/{site}/cmd/{type}` | 下行 | mfrr、mode、rule、ota |
| `ems/{site}/cmd_ack` | 上行 | 指令执行结果（带指令 id，用来计算往返时延） |

QoS：遥测用 0，事件和指令用 1；指令带 id 和过期时间，边缘侧去重并拒绝过期指令。

### 104 联动 ai-scada

ems-core 开 104 子站（公共地址 2）。在 ai-scada 的 fep 里加一个子站连接配置，SCADA 首页出现"储能站"，显示功率和 SOC，可以遥调有功设定值。这一步放在第 3 阶段，需要小改 ai-scada。

### 7.2 其他页

- **控制算法**：mFRR 轨迹分阶段标注（爬坡/保持/降坡的时间点），FCR/LFSM-O 下垂特性曲线（横轴频率、纵轴功率，实时工作点在曲线上移动），附算法说明。
- **规则**：规则表（触发点位、TinyExpr 条件、动作、命中次数），可在线编辑；显示规则匹配耗时统计。
- **设备与点表**：左侧统一数据模型（有功功率、SOC……），右侧并排显示三家厂商的寄存器地址、类型、字序、倍率，点击某个字段高亮各厂商对应寄存器，并显示实时原始值和换算值。
- **技术要点**：和 Qt 作品集相同的写法，每条配数据，例如"WAL + busy_timeout：多线程写入下 SQLITE_BUSY 从 X 次/分钟降到 0"、"规则二分查找：1000 条规则匹配从 X µs 降到 Y µs"、"断网 60s 补传零丢失"。

### 7.3 多人同时访问

仿真状态全站共享：一个访客下发指令，其他访客也能看到。为避免互相干扰：
- 演示操作限频（每个 IP 每 10 秒一次）；
- 页面空闲 10 分钟或每整点自动恢复初始场景（与 ai-scada 的 AUTO_RESET 一致）；
- 页面顶部显示"演示环境，所有访客共享同一个储能站"。
